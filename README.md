# 📊 AI 기반 유튜브 댓글 분석 및 사용자 인사이트 도출 서비스
> 이 서비스는 유튜브 영상의 방대한 댓글 데이터를 AI로 분석해 요약, 감정 분석, 논란 탐지 등의 다양한 결과를 제공하여, 시청자는 물론 크리에이터까지 시청자 인사이트를 한눈에 확인할 수 있도록 정보를 제공하는 서비스입니다.
